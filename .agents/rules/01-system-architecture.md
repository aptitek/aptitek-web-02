# 01 — System Architecture & Technology Stack

> **AptiTek-02 Static Website Architecture Guides**

---

## 1. System Vision & Overview

**AptiTek-02** is a modern static website featuring a sleek, clean, and high-performance design powered by Astro and Material UI 3 Expressive components. It pairs static site generation speed with a rigorous, type-safe frontend foundation designed for developer velocity, accessibility, and robust verification gates.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                 PRESENTATION LAYER                                     │
│  Astro 7 (SSG) • React 19 (@astrojs/react) • Vite 8 • Emotion                          │
├────────────────────────────────────────────────────────────────────────────────────────┤
│                             DESIGN & THEME ENGINE (MUI 3)                              │
│  MUI v9 Core (@mui/material/styles) • Emotion • Solarized Theme System (createTheme)  │
│  Recursive Casual Typography (Variable Font: CASL=1, CRSV=1) • Solarized Palette       │
├────────────────────────────────────────────────────────────────────────────────────────┤
│                           QUALITY ASSURANCE & BUILD PIPELINE                           │
│  pnpm • Wireit Task Graph • Vitest 4 • Playwright (E2E) • ESLint 10 • Husky • Knip    │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 2. Core Technology Stack

| Layer | Technology | Version | Purpose |
| :--- | :--- | :--- | :--- |
| **Package Manager** | `pnpm` | $\ge 9.x$ | **Mandatory.** Fast, deterministic, disk-efficient dependency management. |
| **Framework & SSG** | Astro + React Integration | Astro 7, React 19 | Static site generation, islands architecture, content performance. |
| **Theme & Components** | MUI Material + Emotion | MUI v9 (`@mui/material`) | Material UI 3 Expressive design tokens, `createTheme`, theme-aware components. |
| **Build & Task Caching** | Vite + Wireit | Vite 8, Wireit 0.14 | Instant HMR, deterministic build graph, incremental caching. |
| **Testing & Quality** | Vitest + Playwright | Vitest 4, Playwright 1.63 | Unit testing for tokens/components, browser E2E smoke tests. |
| **Linters & Hooks** | ESLint + Prettier + Husky | ESLint 10, Husky 9, Knip 6 | Strict boundary enforcement, formatting, and pre-commit verification. |

## 4. Architectural Invariants

1. **Static-First & Island Hydration:** All pages are statically generated by default. Interactive MUI components use Astro client directives (`client:load`, `client:idle`, `client:visible`).
2. **Deterministic Task Execution:** All build, test, lint, and typecheck workflows must run through `pnpm` and `wireit`.
3. **Design Token Integrity:** All visual styling, colors, spacing, and typography must flow from `src/tokens/` without hardcoded arbitrary numbers.
